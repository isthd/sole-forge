# スニーカークリエイター 企画書（SOLE FORGE）

> 元資料: `スニーカークリエイター 企画書.pdf`（2026-11-04, 全 7 ページ）をテキスト化したもの。

## 概要

オフラインで動く PWA で、オリジナルのハイカットスニーカーをデザインし、コレクション棚に飾って画像で書き出せる個人用ツールを作る。

- **アプリ名（仮）**: SOLE FORGE
- **コンセプト**: 自分だけの一足を、ネット不要でいつでも作って並べられる「手元のスニーカー工房」
- **ターゲット**: 自分（個人の趣味）。機能とこだわりを優先し、初心者向けの説明やチュートリアルは最小限
- **動作環境**: PWA。初回アクセス後はオフラインで全機能が動く。PC・スマホ・タブレットにレスポンシブ対応
- **表現**: 最初から 3D（Three.js）。ドラッグで回しながら好きな角度でデザインできる
- **ブランド方針**: 形・ロゴ・柄はすべてオリジナル。実在ブランドのシルエットやロゴは収録しない

## 機能要件

MVP は「ハイカット 1 型を 3D で回しながら、色・素材・柄・ロゴで自由に作り、棚に飾って書き出す」までを完結させる。

| 機能 | 内容 | 優先度 |
|---|---|---|
| ベースモデル | ハイカット 1 型（オリジナル形状）。後から型を追加できるデータ構造にする | MVP |
| パーツごとの色 | アッパー、トゥ、ヒールカウンター、アイステイ、シュータン、ライニング、ミッドソール、アウトソール、靴ひも、サイドパネルを個別に着色。HEX 入力・カラーピッカー・最近使った色 | MVP |
| 素材・柄 | レザー、スエード、メッシュ、キャンバス、パテント。柄はグラデーション、迷彩、チェック、ドット。素材は PBR マテリアル（粗さ・光沢・ノーマルマップ）、柄は Canvas で生成したテクスチャ | MVP |
| ロゴ・ステッカー・文字 | 付属のオリジナルマーク、手持ち画像の読み込み、テキスト（フォント・色）。モデル表面をクリックして貼り付け（デカール投影）。移動・拡大・回転・左右反転・重ね順 | MVP |
| 編集操作 | 元に戻す／やり直し、パーツ選択のハイライト、ランダム配色、配色の左右コピー | MVP |
| コレクション棚 | 作品をシューズラックに並べて眺める。棚は保存時のサムネイルで軽く表示し、選ぶと 3D で回して見られる。並べ替え、名前変更、複製、削除、お気に入り | MVP |
| 画像書き出し | 単体（好きな角度で、透過 PNG／背景あり）と棚全体を PNG で保存。解像度は 1x/2x/4x | MVP |
| 保存 | IndexedDB に自動保存。全作品を JSON で書き出し・読み込み（バックアップ／端末間移行） | MVP |
| 3D 表示 | ドラッグで回転、ピンチ・ホイールで拡大。正面・横・後ろ・上のプリセット視点。ライティングで素材の質感を表現 | MVP |
| 追加ベースモデル | ローカット、ランニング、厚底など | 次期 |

## 画面構成とビジュアル

画面は「エディタ」「コレクション棚」「設定」の 3 つ。ストリート系のダーク UI で、作品の色が一番映えるようにする。

1. **エディタ**: 中央にスニーカーの 3D ビュー（ドラッグで回転、パーツをタップで選択）。PC では左にパーツ一覧、右に色・素材・ロゴのパネル。スマホでは下部タブのツールバー＋ボトムシートに切り替え
2. **コレクション棚**: シューズラック風の棚に作品カードを並べる。タップで拡大、長押し（右クリック）でメニュー
3. **設定**: JSON 書き出し・読み込み、書き出し解像度、ストレージ使用量の表示

ビジュアルトーン:
- ベース: ほぼ黒（#0E0E10）＋濃いグレーのパネル
- アクセント: ネオン系 1 色（蛍光ライム #C6FF00）を選択状態やボタンに使う
- フォント: 見出しは太いコンデンス体、本文は Noto Sans JP。いずれもアプリに同梱してオフラインで表示
- 質感: コンクリート調の背景やステッカー風ラベルをさりげなく使い、キャンバス周りは無地にして作品を主役にする
- 操作: マウス・タッチ両対応。ピンチで拡大、2 本指でパン、キーボードショートカット（Ctrl+Z など）

## 技術構成とデータ設計

React ＋ TypeScript ＋ Vite で作り、描画をレンダラーとして分離しておくことで、データと UI をそのまま使い回す。

| 領域 | 採用技術 | 理由 |
|---|---|---|
| フレームワーク | React 18 + TypeScript + Vite | 型安全、Claude Code との相性が良い |
| PWA | vite-plugin-pwa（Workbox） | 全アセットをプリキャッシュしてオフライン動作 |
| 状態管理 | Zustand + zundo | 軽量、Undo/Redo 履歴を簡単に持てる |
| 保存 | IndexedDB（Dexie.js） | 画像付きの作品データを容量を気にせず保存 |
| 3D 描画 | Three.js + @react-three/fiber + drei | 3D シーンを React 部品として書け、回転・拡大・クリック判定がそろう |
| 画像書き出し | WebGL キャンバス → PNG | 好きな角度を高解像度で再レンダリングして保存 |
| 3D モデル | Three.js のコードで手続き的に生成 | 外部ファイル不要でオフラインに強く、寸法をパラメータで調整できる。パーツごとに名前付きメッシュにして色・素材を個別に適用 |
| テスト | Vitest + Playwright | データ層の単体テストとオフライン動作の E2E |

### データモデル

```ts
type PartId = 'upper' | 'toe' | 'heel' | 'eyestay' | 'tongue'
  | 'lining' | 'midsole' | 'outsole' | 'laces' | 'sidePanel';

interface PartStyle {
  color: string;            // HEX
  material: 'leather' | 'suede' | 'mesh' | 'canvas' | 'patent';
  pattern?: { type: 'gradient' | 'camo' | 'check' | 'dot'; colors: string[] };
}

interface Decal {
  id: string;
  kind: 'logo' | 'image' | 'text';
  src?: string;             // 画像は Blob のキー
  text?: string; font?: string; color?: string;
  part: PartId;             // 貼り付け先パーツ（メッシュ名）
  position: [number, number, number]; // モデル表面上の位置
  normal: [number, number, number];   // 投影方向
  scale: number; rotation: number; flip: boolean; z: number;
}

interface SneakerDesign {
  id: string; name: string;
  baseModel: 'hightop-01';  // 将来追加
  parts: Record<PartId, PartStyle>;
  decals: Decal[];
  camera?: { position: [number, number, number]; target: [number, number, number] }; // 最後に見ていた角度
  thumbnail?: string;       // 棚表示用 PNG の Blob キー
  favorite: boolean; shelfOrder: number;
  createdAt: string; updatedAt: string;
  schemaVersion: 1;
}
```

- ベースモデルは Three.js のコードで組み立てる。ソールは押し出し（ExtrudeGeometry）、アッパー各パーツは断面の曲線をつないだ曲面、靴ひもはチューブ（TubeGeometry）で作り、パーツ ID と同じ名前のメッシュにする
- 型ごとに「寸法パラメータ（長さ・高さ・ソール厚・つま先の反り）＋パーツ生成関数」を 1 ファイルにまとめ、型の追加はファイル追加だけで済むようにする
- JSON 書き出しは画像を Base64 に埋め込んだ 1 ファイル。読み込み時は schemaVersion でマイグレーションする
- スマホでも軽く動くよう、ポリゴン数は 1 足あたり約 5 万以下、テクスチャは 1024px 以下、描画は操作中のみ更新する

## 開発ロードマップ

MVP は 基盤 → エディタ → 飾る・保存 → PWA 化 の 4 フェーズで進め、受け入れ基準を満たしたら型追加へ進む。3D はフェーズ 1 から組み込む。各フェーズの終わりにビルドとテストを通してから次へ進む。

- フェーズ 1 基盤: Vite + React + TypeScript、Zustand + zundo、Dexie、データモデル、手続き生成のハイカット 3D モデル（10 パーツの名前付きメッシュ）、R3F + drei の 3D ビュー（回転・拡大・プリセット視点）
- フェーズ 2 エディタ: パーツ選択（ハイライト）、色・素材（PBR）・柄（Canvas）、ロゴ・画像・文字のデカール（移動・拡大・回転・反転・重ね順）、Undo/Redo 50 手以上、ランダム配色、左右コピー
- フェーズ 3 飾る・保存: コレクション棚、PNG 書き出し（単体／棚全体、1x/2x/4x）、全作品の JSON 書き出し・読み込み
- フェーズ 4 PWA 化: vite-plugin-pwa で全アセット（フォント含む）をプリキャッシュ、Playwright でオフライン E2E

守ること:
- 外部ネットワークへのリクエストは禁止。フォント・画像・テクスチャはすべて同梱する
- 実在ブランドのシルエットやロゴは使わない。付属ロゴもオリジナルで作る
- UI はストリート系ダーク（背景 #0E0E10、アクセント #C6FF00）、PC・スマホ両対応のレスポンシブ
- スマホでも回転 30fps 以上を保つ（1 足 5 万ポリゴン以下、テクスチャ 1024px 以下）

## 受け入れ基準（MVP）

1. 機内モードでアプリを開き、新規作成から保存まで全操作できる
2. 3D ビューで回転・拡大・プリセット視点の切り替えができる
3. 10 パーツすべてに色・素材・柄を設定できる
4. ロゴ・画像・文字をモデル表面に貼り、移動・拡大・回転できる
5. Undo/Redo が 50 手以上効く
6. 棚で並べ替え・複製・削除ができ、再起動後も残っている
7. 単体（好きな角度）と棚全体を PNG（最大 4x）で書き出せる
8. JSON で書き出した全作品を別端末で読み込んで復元できる
9. 幅 360px のスマホと 1440px の PC で操作が破綻せず、スマホでも回転が 30fps 以上で動く
